1. KÜNYE — SİSTEM BİLGİLERİ
================================================================================

Proje adı        : excel-arsiv (npm) / Excel Arşiv (marka)
Alan adı         : excelarsiv.com (hedef yayın adresi)
İş modeli        : Türkiye'deki ticari işletmelere finans, muhasebe ve
                   operasyon amaçlı hazır Excel çalışma tabloları (dijital ürün)
Ödeme altyapısı  : Shopier (dijital ürün teslimatı Shopier panelinden)
Barındırma       : Firebase Hosting (statik, sunucusuz)
Ürün aşaması     : ALTYAPI TAMAM; ürün içerikleri bekliyor (kullanıcı kararı)

Teknoloji özeti:
- Astro 7.x (statik çıktı, sıfır istemci JavaScript hedefi)
- Tailwind CSS v4 (@tailwindcss/vite) + özel token katmanı
- MDX (@astrojs/mdx) — her ürün bir .mdx dosyası
- Content Collections (astro:content) + Zod şema doğrulaması
- Sitemap (@astrojs/sitemap) — otomatik sitemap-index.xml
- Self-host fontlar: Inter 400/600 + JetBrains Mono 400 (woff2, latin-ext)

Sürümler (package.json, [Kesin]):
  astro              ^7.1.6        (build çıktısı: astro v7.1.6)
  @astrojs/mdx       ^7.0.5
  @astrojs/sitemap   ^3.7.3
  @tailwindcss/vite  ^4.3.3
  tailwindcss        ^4.3.3
  node engine        >=22.12.0
  type               module (ESM)

Yapılandırma dosyaları:
  astro.config.mjs : site https://excelarsiv.com, trailingSlash 'never',
                     tailwindcss vite plugin, mdx + sitemap entegrasyonları
  tsconfig.json    : astro/tsconfigs/strict
  firebase.json    : hosting dist/, cleanUrls, cache başlıkları
  .gitignore       : kök, node_modules/dist/.astro dışlanır

Scriptler:
  npm run dev      → astro dev
  npm run build    → astro build (dist/ çıktısı)
  npm run preview  → astro preview (yerel yayın önizlemesi, 4321)

SLUG KURALI (KIRICI karar, kullanıcı onaylı):
  - Şemada ayrı slug alanı YOKTUR.
  - URL, ürün adından otomatik türetilir ve ürün adını TAM içerir.
  - src/utils/slug.ts: Türkçe harfler → ascii (ç→c, ğ→g, ı→i, ö→o, ş→s, ü→u),
    boşluk/noktalama → tire, fazla tire temizlenir.
  - Örnek: "Akıllı Kasa Defteri ve Nakit Kontrol Sistemi"
        → /sablon/akilli-kasa-defteri-ve-nakit-kontrol-sistemi
  - Ürün adı değişirse URL de değişir (301/redirect yönetimi GATE 4 sonrası).
  - Kategori ve üst sayfa slug'ları TÜRKÇEDİR (SEO kararı):
      /sablonlar, /sablonlar/nakit-akisi, /nasil-calisir, /sss

4. KODLAMA DNA'SI — KONVANSİYONLAR VE KURALLAR
================================================================================

4.1 Dil disiplini (kullanıcı kararı):
  - Kod tanımlayıcıları, dosya adları, prop adları, şema alanları,
    CSS sınıf/token adları: %100 İNGİLİZCE.
  - Kullanıcıya görünen metin (arayüz, ürün adları, SSS içerikleri): TÜRKÇE.
  - URL slug'ları: TÜRKÇE (SEO kararı, yukarıda).
  - Bu ayrım bilinçlidir ve dokunulmaz.

4.2 Release Mandate kuralları (excelarsiv-release-mandate.md):
  - Yalnızca açık tema; renk token'ları :root'da tek kaynak.
  - Köşe yarıçapı istisnasız 0.
  - Hareket yalnızca opacity/transform; 120–180ms; ease-out;
    prefers-reduced-motion'da sıfırlanır.
  - Self-host fontlar (Inter + JetBrains Mono), latin-ext alt küme.
  - Statik üretim, sıfır istemci JS.
  - Görünen metin Türkçe; ticari kısaltmalar korunur (KDV, SGK, VUK vb.).

4.3 Genel kod standardı:
  - TypeScript strict (astro/tsconfigs/strict).
  - Bileşen arayüzleri: interface Props { ... }, Astro.props destructuring.
  - Astro dışı mantık yardımcılarda: src/utils/.
  - Veri alanı adları şemayla birebir; sayfalar t.data üzerinden okur.
  - HTML semantik: dl/dt/dd (künye), ol/li (indeks), figure/figcaption,
    table (spec), details/summary (SSS), nav/header/footer/main landmark.
  - Tekrar eden stiller global.css @layer components altında
    (btn-primary, btn-secondary, h1, h2, h3, lead, kicker, container-site,
    section-pad, display, mono-xs, body-sm).
  - Erişilebilirlik: global :focus-visible, aria-current, aria-hidden
    dekoratif öğelerde, scroll-margin-top çapa hedefleri için.
  - Kod İngilizce; yorum varsa İngilizce ve gerekçeli (ihtiyaç/trade-off).

4.4 Proje invaryantları (değişmez kurallar):
  - Şema değişikliği = KIRICI, onay ister.
  - Ham hex renk yalnızca global.css'te; bileşenlerde token sınıfı kullanılır.
  - Rota değişikliği URL yapısını bozar, onay ister.
  - Görünen Türkçe metinler İngilizceye çevrilmez.
  - Ürün eklerken demo .xlsx + en az 3 ekran görüntüsü zorunlu (build patlar).
  - Sitede sepet/form yok; ödeme shopierUrl ile yeni sekmede.

9. SHOPIER ENTEGRASYONU — KARAR NOTU
================================================================================

  - Satın alma akışı: ürün sayfasındaki shopierUrl → yeni sekmede Shopier
    güvenli ödeme sayfası. Sitede sepet ve ödeme formu YOKTUR.
  - Dijital ürün teslimatı: Shopier panelindeki dijital teslimat ayarına
    bağlı; indirme bağlantısı alıcının e-postasına gider.
  - IPN / post_sale_callback: doğrulama imzası 4 parçalıdır —
    random_nr + platform_order_id + total_order_value + currency,
    HMAC-SHA256. Şu an işlenmiyor (ürünler statik, satış sonrası yok);
    gerekirse ayrı sunucusuz uç ile kurulur. JS SDK imza hesabı (2 parçalı)
    referans alınmaz; 4 parçalı doğrulama esastır [Güçlü].
  - Teslim süresi metni şu an "Shopier ayarına bağlıdır, yayın öncesi test
    siparişiyle doğrulanır" — GATE 6: canlı test siparişi (kullanıcı hesabı).
